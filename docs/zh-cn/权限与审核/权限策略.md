# 权限策略

## 工具权限策略
- 权限基于当前 Agent 配置（例如代码探索 Agent 只有只读工具）。

- Shell 工具可以执行任意命令，非白名单命令默认需要用户审核。

- 白名单命令来自配置 `[permissions].allow_commands`（项目配置优先，可回退全局配置），支持"精确匹配 + 通配符匹配"（如 `git status`、`gh pr view *`），且命令不含链接符（`;`/`&`/`|`）时才能命中白名单。危险模式（如 `rm -rf /`、链接符 `;`/`&`/`|` 绕过）硬编码拒绝。非白名单命令进入审核列表。

- 会话模式：**手动模式**下所有编辑/写入操作均需用户审核；**接受编辑模式**下本会话内工作区中的文件编辑和写入自动放行，工作区外的编辑/写入仍需用户审核。模式切换通过快捷键(Shift+Tab)/GUI中的按钮进行。
  > 模式需要支持未来可能的更多扩展
  
- 完全禁止读写系统文件或用户私密数据。

- 当解析到当前 Agent 无权使用的工具时，在工具输出中给出明确错误并放入结果，不静默跳过。


## 审核决策矩阵

> 当前实现仅有 Read、Edit、Write、Shell、Skill 五个工具；Stat、Glob、Grep、AskUserQuestion 为规划中工具。

| 工具 | 检查路径 | 检查命令 | 模式依赖 | 工作区外 |
|------|----------|----------|----------|----------|
| Read | 是 `file_path`（`ReadPath`） | — | — | 需审核 |
| Edit / Write | 是 `file_path`（`WritePath`） | — | 是 手动→全审；接受编辑→仅区外 | 需审核 |
| Shell | — | 是 `command`（`Command`） | — | — |
| Skill | — | — | — | 始终免审（只读概念） |

**特殊路径规则**：`Auditor` 支持通过 `with_exempt_paths` 注入额外豁免路径；工作区外的被豁免路径目前同样需要审核（`NeedsApproval`），而非直接放行。完全禁止读写系统文件或用户私密数据是产品目标，当前由工作区边界与命令黑名单共同约束。

## 权限审核（Auditor）

审核器**不硬编码工具名**，而是通过遍历参数的 `semantic` 字段泛化判断。
