# 核心工作流

1. 用户在项目目录下运行 `manualaid-cli`（loop 模式），CLI 启动时自动确保项目 `.ManualAid/config.toml` 与 `.gitignore` 存在，加载全局/项目配置与技能。
2. 在数字菜单中可切换语言、工具调用格式、审批模式（Manual ↔ AcceptEdit），并复制系统提示词。
3. 用户将系统提示词与自身要求粘贴到网页端发送给大模型。
4. 大模型回复包含工具调用格式时，用户复制模型回复。
5. 回到 `manualaid-cli`，选择“粘贴并提交”或“输入并提交”；也可直接输入 `/` 开头的内置命令。
6. `manualaid-cli` 按照当前设置的格式（`auto` / `json-codeblock` / `invoke` / `xml`）解析工具调用。工作区内的只读工具直接执行，工作区外的只读操作仍需审核；需要审核的编辑/写入工具按逐条文本提示依次询问用户：`y` 同意、`n` 拒绝、`t` 拒绝并键入文本。
7. 解析器产生的软警告（如未闭合参数被丢弃）会以 `⚠` 提示输出。
8. 工具执行结果默认自动复制到剪贴板（可在配置中调整或由菜单开关控制），用户将结果粘贴给大模型，循环往复。

> 智能永久同意建议卡片、GUI 主窗口与内联审核卡片均为规划中的交互，当前版本未实现。
