# 更新日志

## [Unreleased]

## [0.13.0] - 2026-09-10

### 新增

- 新增 `/compress`、`/plan`（`/p`）、`/build`（`/b`）、`/skills` 快捷命令：在输入框直接复制压缩会话、计划模式、切换执行模式提示词与已启用 SKILL 列表；`/tools` 改为复制已启用工具的完整列表模板
- 复制提示词菜单新增“复制已启用 SKILL 列表”，并把“复制当前已启用工具列表”升级为复制完整工具列表模板（含参数与调用模板）；工具与 SKILL 列表复制内容统一以 `<system-reminder>` 块包裹
- `!` 命令的执行结果现在以 `[USER_ACTION kind="exec" command="…"] … [END USER_ACTION]` 形式回贴，明确标记这是用户直接发起的操作，而非工具自动调用
- 系统提示词新增 USER_ACTION 说明，让外部模型识别用户驱动操作块的含义，避免重复执行用户已发起的命令
- 主菜单输入现在支持交互式补全：输入 `/` 会提示内置命令与可用技能，输入 `@` 会提示项目文件与文件夹；`/SKILL` 与 `@path` 分别作为用户主动加载技能和引用路径生效，并产生对应 USER_ACTION 结果块
- 主菜单输入补全编辑器恢复历史回溯与光标移动：无补全面板时按上下方向键切换历史输入，左右方向键在行内移动光标，Ctrl+方向键按词移动；相同输入只保留最新一条历史，中文等多字节字符下光标依然对齐
- 工具执行期间在当前行显示进度：`(秒数) 工具1, 工具2, ...`，每个工具按状态着色（未执行灰色、执行中黄色、成功绿色、失败红色），执行结束后该行保留并换行，再输出原有的结果摘要与耗时信息；审批阶段不显示计时

### 变更

- 技能工具的说明从“不要调用已在运行的技能”调整为“不要调用已经加载过的技能”，避免把“已加载”误解为“正在执行”，减少重复调用同一技能
- 更新日志查看器现在会跟随界面语言：英文界面显示英文内容，中文及其它语言显示中文内容

## [0.12.0] - 2026-09-09

### 新增

- 会话压缩摘要现在会过滤脏话、人身攻击等情绪化表达，只保留中性技术信息，避免攻击性内容影响后续会话的表现
- 交互式 loop 启动时把终端窗口标题设为 `[ManualAid] <项目文件夹名>`，多个项目的会话在窗口与标签栏中一眼可辨

### 变更

- 技能命名与解析重构：每个技能拥有稳定的完整唯一名称（`<作用域>-<目录>-<名称>`，如 `project-.agents-pdf`）；代理在可用技能列表与 Skill 工具中看到的名称在无冲突时保持简短（技能名），同名时自动带上前缀，管理界面始终显示完整唯一名称
- 技能重复检测更宽容：行尾风格（LF/CRLF）与首尾空白不同的相同技能视为重复

## [0.11.0] - 2026-09-07

### 新增

- 编辑失败时仅给出最关键的诊断信息：换行符不一致时直接提示调整方式，内容相似时只给出参考文本，不再同时输出“请重新读取文件”等无关提示

### 修复

- 移除系统提示中“Windows 下使用正斜杠路径”的建议，避免该指引引发路径解析失败

## [0.10.3] - 2026-09-05

### 新增

- Skill 工具执行结果新增技能文件夹绝对路径字段，帮助 Agent 正确解析技能内脚本与参考文件的相对路径
- 编辑失败时，换行符差异提示现在会直接告诉将 `old_string` 与 `new_string` 切换为文件匹配片段使用的换行符后重试
- 读取文件时页脚自动提示文件行尾风格（LF/CRLF/混合），无需手动开启行尾诊断

### 修复

- 修复混合换行文件中，编辑工具可能错误提示匹配片段使用 CRLF 的问题

## [0.9.0] - 2026-08-26

### 新增

- 系统提示词 `path-rules` 新增 @ 前缀文件读取规则
- 复制提示词菜单新增“复制上下文”，支持选择多个工作区上下文文件
- 复制提示词菜单新增“复制压缩会话提示词”，粘贴到会话中即可让模型压缩当前会话
- 工具结果超出字符上限被截断时，完整输出会暂存到 `.ManualAid/temp/` 下的文件，截断提示中会告知文件位置和每个工具输出的行号

### 变更

- `<directory_listing>` 块开头新增快照说明，提示目录结构为启动时快照不会后续更新
- JSON 代码块（json-codeblock）工具调用模板的行尾转义说明细化：区分 LF 与 CRLF 的转义写法
- 工作区上下文文件改为在系统提示词末尾的独立提示块中展示，文件标签本地化
- 系统提示词 `path-rules` 移除对 `<context_files>` 的路径来源引用

### 修复

- 补齐中文系统提示词 `path-rules` 缺失的目录列出与 Windows 正斜杠规则，与英文版对齐
