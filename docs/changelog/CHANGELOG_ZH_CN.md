# 更新日志

## [Unreleased]

## [0.11.0] - 2026-09-07

### 新增

- 编辑失败时仅给出最关键的诊断信息：换行符不一致时直接提示调整方式，内容相似时只给出参考文本，不再同时输出“请重新读取文件”等无关提示

### 修复

- 移除系统提示中“Windows 下使用正斜杠路径”的建议，避免该指引引发路径解析失败

## [0.10.3] - 2026-09-05

### 新增

- Skill 工具执行结果新增技能文件夹绝对路径字段，帮助 Agent 正确解析技能内脚本与参考文件的相对路径
- 编辑失败时，换行符差异提示现在会直接告诉将 `old_string` 与 `new_string` 切换为文件匹配片段使用的换行符后重试
- 读取文件时页脚自动提示文件行尾风格（LF/CRLF/混合），无需手动开启行尾诊断

### 修复

- 修复混合换行文件中，编辑工具可能错误提示匹配片段使用 CRLF 的问题

## [0.10.2] - 2026-09-04

### 修复

- 简化默认拒绝提示为单纯的拒绝声明，移除命令内容、白名单状态与批准要求等冗余描述

## [0.10.1] - 2026-08-30

### 变更

- 意图输出提示词替换为系统级规则，并采用新的意图块格式

## [0.10.0] - 2026-08-27

### 新增

- 新增 `manualaid-cli copy` 命令，无需进入交互菜单即可直接复制 10 种提示词；复制系统提示词或上下文文件时可使用 `--context-files` 选择加载范围

## [0.9.0] - 2026-08-26

### 新增

- 系统提示词 `path-rules` 新增 @ 前缀文件读取规则
- 复制提示词菜单新增“复制上下文”，支持选择多个工作区上下文文件
- 复制提示词菜单新增“复制压缩会话提示词”，粘贴到会话中即可让模型压缩当前会话
- 工具结果超出字符上限被截断时，完整输出会暂存到 `.ManualAid/temp/` 下的文件，截断提示中会告知文件位置和每个工具输出的行号

### 变更

- `<directory_listing>` 块开头新增快照说明，提示目录结构为启动时快照不会后续更新
- JSON 代码块（json-codeblock）工具调用模板的行尾转义说明细化：区分 LF 与 CRLF 的转义写法
- 工作区上下文文件改为在系统提示词末尾的独立提示块中展示，文件标签本地化
- 系统提示词 `path-rules` 移除对 `<context_files>` 的路径来源引用

### 修复

- 补齐中文系统提示词 `path-rules` 缺失的目录列出与 Windows 正斜杠规则，与英文版对齐

## [0.8.0] - 2026-08-25

### 新增

- 主菜单支持 `!` 前缀直接运行 Shell 命令
- 设置菜单新增内置更新日志查看器

### 变更

- 工具输出分页改为每页三行
- 审批预览与 Diff 输出分页改为首次 20 行、之后每次 10 行

## [0.7.0] - 2026-08-21

### 新增

- 工具结果显示重要参数摘要
- Read 输出末尾追加范围/行数标记
- 未闭合工具调用作为失败结果保留
- 配置菜单新增复制提示词子菜单，支持复制意图规则、工具格式、启用工具列表、行尾处理规则、计划模式规则、切换执行模式规则和任务规划规则

### 变更

- 默认解析器顺序调整为 json-codeblock、invoke、xml
- 统一菜单与内联命令处理

## [0.6.0] - 2026-08-18

### 新增

- 支持 invoke 工具调用格式

### 修复

- 修复 XML 参数值中裸 `<` 误吞后续标签的问题

## [0.5.0] - 2026-08-18

## [0.4.1] - 2026-08-16

## [0.4.0] - 2026-08-15

### 新增

- 新增 `debug plan_edit`：预检 Edit 匹配情况

### 变更

## [0.3.1] - 2026-08-15

## [0.1.0] - 2026-08-09

### 新增

- 初始发布 ManualAid Rust 重构版
- 支持无参数启动交互式 Agent Loop
- 内置 Read、Edit、Write、Shell、Skill 五种工具
- 支持技能发现与加载
- 支持会话轮次日志与结果复制
- 提供 init、dir、mask、restore、skill 等命令行子命令
