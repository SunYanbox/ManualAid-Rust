# 更新日志

## [0.3.0] - 2026-08-14

### 新增

- 支持按启用工具过滤解析，并显示解析软警告
- 复制意图规则快捷命令
- 生成系统提示词与轮次执行时显示 Token 估算

### 修复

- 剪贴板读写改为可注入的 Provider 抽象，测试不再污染系统剪贴板

## [0.2.0] - 2026-08-12

### 新增

- 工具历史列表，显示每轮工具、耗时与 Token 统计
- 复制轮次结果时显示详细预览
- 配置菜单新增“查看内存会话占用”
- Windows 平台提示词新增平台说明

### 修复

- 修复 Windows 下 cmd Shell 命令引号解析冲突
- 修复读取目录时未在审批前拦截的问题

## [0.1.0] - 2026-08-09

### 新增

- 初始发布 ManualAid Rust 重构版
- 支持无参数启动交互式 Agent Loop
- 内置 Read、Edit、Write、Shell、Skill 五种工具
- 支持技能发现与加载
- 支持会话轮次日志与结果复制
- 提供 init、dir、mask、restore、skill 等命令行子命令
- 支持中英文界面切换
- 提供权限审核、隐私掩码与 Shell 白名单
