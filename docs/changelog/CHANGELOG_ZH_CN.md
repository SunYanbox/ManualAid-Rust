# 更新日志

## [Unreleased]

### 新增

- 系统提示词 `path-rules` 新增 @ 前缀文件读取规则

### 变更

- `<directory_listing>` 块开头新增快照说明，提示目录结构为启动时快照不会后续更新

### 修复

- 补齐中文系统提示词 `path-rules` 缺失的目录列出与 Windows 正斜杠规则，与英文版对齐

## [0.8.0] - 2026-08-25

### 新增

- 主菜单支持 `!` 前缀直接运行 Shell 命令
- 设置菜单新增内置更新日志查看器

### 变更

- 工具输出分页改为每页三行
- 审批预览与 Diff 输出分页改为首次 20 行、之后每次 10 行

## [0.7.0] - 2026-08-21

### 新增

- 工具结果显示重要参数摘要
- Read 输出末尾追加范围/行数标记
- 未闭合工具调用作为失败结果保留
- 配置菜单新增复制提示词子菜单，支持复制意图规则、工具格式、启用工具列表、行尾处理规则、计划模式规则、切换执行模式规则和任务规划规则

### 变更

- 默认解析器顺序调整为 json-codeblock、invoke、xml
- 统一菜单与内联命令处理

## [0.6.0] - 2026-08-18

### 新增

- 支持 invoke 工具调用格式

### 修复

- 修复 XML 参数值中裸 `<` 误吞后续标签的问题

## [0.5.0] - 2026-08-18

### 新增

- 新增 `debug whitelist` 命令查看 Shell 白名单
- 新增内联快捷命令：`/help`、`/history`、`/summary`、`/clear`、`/mode`，并支持 `/h`、`/H`、`/s`、`/cls`、`/m` 等别名

### 变更

- 扩充默认 Shell 白名单
- 更新提示词与工具描述

## [0.4.1] - 2026-08-16

### 新增

- Read 工具支持显示行号和行尾标记

### 变更

- Edit 找不到 `old_string` 时给出更明确的换行差异或相似文本提示

## [0.4.0] - 2026-08-15

### 新增

- 新增 `debug plan_edit`：预检 Edit 匹配情况
- 新增 `debug shell`：预览、确认并执行 Shell 命令
- 原 `mask`、`restore`、`skill` 命令迁移为 `debug` 子命令

### 变更

- XML 解析器对 CDATA 闭合更严格，未闭合参数会给出软警告

## [0.3.1] - 2026-08-15

### 变更

- Edit 成功结果现在显示行数变化和 diff
- XML 解析器优化 CDATA 空白处理和空字符串参数

## [0.3.0] - 2026-08-14

### 新增

- 支持按启用工具过滤解析，并显示解析软警告
- 复制意图规则快捷命令
- 生成系统提示词与轮次执行时显示 Token 估算

### 修复

- 剪贴板读写改为可注入的 Provider 抽象，测试不再污染系统剪贴板

## [0.2.0] - 2026-08-12

### 新增

- 工具历史列表，显示每轮工具、耗时与 Token 统计
- 复制轮次结果时显示详细预览
- 配置菜单新增“查看内存会话占用”
- Windows 平台提示词新增平台说明

### 修复

- 修复 Windows 下 cmd Shell 命令引号解析冲突
- 修复读取目录时未在审批前拦截的问题

## [0.1.0] - 2026-08-09

### 新增

- 初始发布 ManualAid Rust 重构版
- 支持无参数启动交互式 Agent Loop
- 内置 Read、Edit、Write、Shell、Skill 五种工具
- 支持技能发现与加载
- 支持会话轮次日志与结果复制
- 提供 init、dir、mask、restore、skill 等命令行子命令
- 支持中英文界面切换
- 提供权限审核、隐私掩码与 Shell 白名单
