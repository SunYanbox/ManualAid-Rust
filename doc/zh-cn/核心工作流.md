# 核心工作流

1. 用户在项目目录下启动 ManualAid，弹出主窗口。
2. 用户切换所需的 Agent（如有需要）、UI语言、提示词与工具提示语言、模式（自动、手动审核、接受编辑）。
3. 用户通过快捷按钮复制系统提示词。
4. 用户将提示词与自身要求粘贴到网页端发送给大模型。
5. 大模型回复包含工具调用格式时，用户复制模型回复。
6. 回到 ManualAid，点击“粘贴并提交”或“提交”按钮。
7. ManualAid 按照当前设置支持的格式（如自定义 XML、类 Anthropic JSON 等）解析工具调用。工作区内的只读工具直接执行，工作区外的只读操作仍需审核；需要审核的编辑/写入工具依次在工具记录区域底部**内联弹出审核卡片**，用户选择同意/拒绝/拒绝并键入文本。
8. 当系统检测到用户在同一会话内多次同意相似操作时，弹出**智能永久同意建议卡片**，用户可选择将规则添加到项目或全局配置。
9. 工具执行结果自动复制到剪贴板（可配置开关），用户将结果粘贴给大模型，或继续补充说明，循环往复。
