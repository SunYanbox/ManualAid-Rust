# 内置命令与辅助功能

> **当前状态**：以下 `/` 开头的内置命令属于旧版计划中的程序内命令，当前版本处于**考虑中**阶段，尚未完整实现。实际使用请参考 CLI 程序参数（如 `manualaid-cli init`、`manualaid-cli loop` 等）。

## 内置命令列表（均以 `/` 开头，考虑中）
- `/ws`：复制工作区系统提示词。
- `/tools`：列出已有工具列表与简述作用。
- `/c [i]`：复制最新的第 i 次工具调用结果（i 可选，默认 1）。
- `/c t 工具名称`：复制指定工具的标准调用格式。
- `/lang [索引]`：无参数时循环切换界面语言（en → zh-CN → …）；带索引时切换到列表中的第 index 项。
- `/format [索引]`：无参数时循环切换工具调用格式（auto → xml → json-codeblock → …）；带索引时直接切换。
- 命令解析要求 `/` 后紧跟命令名及必需空格或参数。

## 命令结果输出（考虑中）
- 内置命令的结果显示在工具记录窗口。
- `/c` 系列指令将内容复制到剪贴板，并在窗口中给出确认信息。

## 技能命令（考虑中）
- `/技能名称 `（末尾必须有空格）用于触发技能，输入后点击“转换到提示词构建列”将其加入记录面板，供后续整理。

## 工具标准调用格式
- 由解析器层 `ToolCallFormatParser::tool_call_template()` 根据当前设置的调用格式（XML 或 JSON）动态生成标准调用模板；工具不感知格式，避免硬编码。
