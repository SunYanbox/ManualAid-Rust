# 内置命令与辅助功能

CLI 交互循环（`loop_cli`）中支持以 `/` 开头的内置命令。这些命令在输入后立即执行。

## 已实现的内置命令（CLI）

| 命令 | 别名 | 功能 |
|------|------|------|
| `/help` | `/h`, `/?` | 显示所有可用内联命令的帮助信息 |
| `/mode` | `/m` | 切换审批模式（Manual ↔ AcceptEdit），切换后即时生效 |
| `/clear` | `/cls` | 清屏 |
| `/history` | `/H` | 显示工具调用历史记录 |
| `/summary` | `/s` | 显示当前会话摘要（包含工具调用统计等） |
| `/ws` | — | 复制工作区系统提示词到剪贴板 |
| `/tools` | — | 列出所有可用工具及其简要描述 |
| `/c [i]` | — | 复制第 i 次工具调用结果到剪贴板（i 默认 1，表示最近一次） |
| `/c t 工具名称` | — | 复制指定工具的标准调用模板到剪贴板 |
| `/lang [索引]` | — | 无参数时循环切换界面语言（en → zh-CN → …）；带索引时切换到列表中的第 index 项 |
| `/format [索引]` | — | 无参数时循环切换工具调用格式（auto → xml → json-codeblock → …）；带索引时直接切换 |

> **注意**：命令解析要求 `/` 后紧跟命令名，参数前需有空格。

## 审批模式切换（/mode）

`/mode` 或 `/m` 命令用于在两种会话模式间切换：

| 模式 | 行为 |
|------|------|
| `Manual`（默认） | 每次写入/编辑操作都需要用户批准 |
| `AcceptEdit` | 工作区内的写入/编辑操作自动放行；工作区外的操作仍需批准 |

切换后立即生效，并显示当前模式名称。该状态仅在当前会话中有效，退出后恢复为配置文件中的默认值。

## 命令结果输出

- 内置命令的结果直接输出到终端（如 `/help` 显示帮助文本，`/summary` 显示会话摘要）。
- `/ws`、`/c`、`/c t` 等涉及剪贴板操作的命令，除复制内容到剪贴板外，还会在终端输出确认信息。

## 技能命令（规划中）

- `/技能名称 `（末尾必须有空格）用于触发技能，输入后加入记录面板供后续整理。该功能处于规划阶段，尚未实现。

## 工具标准调用格式

- 由解析器层 `ToolCallFormatParser::tool_call_template()` 根据当前设置的调用格式（XML 或 JSON）动态生成标准调用模板；工具不感知格式，避免硬编码。
