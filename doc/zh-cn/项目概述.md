# 项目概述

## 详细需求列表

- 从文件系统（项目路径，Agent记忆文件，git status，根文件夹存在的文件与文件夹名称）构建系统提示词。**构建方式**：不使用模板引擎，采用纯字符串拼接，并默认硬编码忽略 `.git`、`node_modules`、`.venv` 等超大目录。
- 读写用户目录（`C:\Users\<用户名>`、`/home/<用户名>`、`/Users/<用户名>`）来加载`.agents`、`.claude`等文件夹下的agents、skills等文件夹的数据。
- 工具与工具权限。Agent及其权限相关功能。
- 一个可以支持折叠控件+Markdown显示+弹出窗口的GUI库。
- 跨平台获取剪切板内容，复制内容到剪切板的功能
- 数据库持久化Session（会话）、工具调用记录、工具调用结果，编辑类工具审核+编辑记录（用于回滚更改）。项目配置文件（`.ManualAid/config.toml`）持久化项目级永久同意规则，全局配置文件持久化全局级永久同意规则。
- 基于文本的Diff、基于文件的Diff与GUI可视化。
- 国际化文本，支持多语言。
- 工具
  - 读取文件（`Read`），编辑文件（`Edit`），写入文件（`Write`），获取文件/目录元数据(大小、修改时间、行数)（`stat`）
  - 搜索文件（`Glob`），搜索内容（`Grep`）
  - 向用户询问（`AskUserQuestion`）
  - 终端（`Shell`）
  - 加载技能（`Skill`）
  
- Agent
  - Agent名称与描述
  - Plan Agent，Explore Agent，通用Agent

- **多格式调用支持**：系统支持多种工具调用格式（如本项目的自定义 XML、类 Anthropic JSON 代码块等），解析器能识别任意已配置的格式并正确调用。用户可在设置中切换当前生效的调用格式。
- **工具标准调用格式**：模板生成由**解析器层**负责，而非工具定义层。每个工具只定义纯数据（名称、描述、参数列表）。每种调用格式的解析器（如 XML、JSON 代码块）通过实现 `ToolCallFormatParser` trait，提供 `try_parse()`（解析输入）和 `tool_call_template()`（渲染对应格式的调用模板）两个方法——**解析和渲染对称设计**。新增调用格式只需实现该 trait 并注册到 `FormatRegistry`，无需修改任何工具定义。

## 可能用到的库

### 1. 跨平台 UI 开发库
- **需求描述**：多平台支持（桌面/Web/移动端）且高性能的 Rust UI 框架。
- [Tauri](https://v2.tauri.app/)(`cargo install create-tauri-app --locked`) + [Vue](https://cn.vuejs.org/)(`pnpm create vue@latest`)

### 2. 剪贴板操作库
- **需求描述**：获取剪贴板内容、复制内容到剪贴板（支持文本/图片/文件等）。
- [@tauri-apps/plugin-clipboard-manager | Tauri](https://v2.tauri.app/zh-cn/reference/javascript/clipboard-manager/)

### 3. 数据库操作库
- **需求描述**：支持 SQL、ORM、嵌入式数据库等操作。
- [rusqlite/rusqlite: Ergonomic bindings to SQLite for Rust](https://github.com/rusqlite/rusqlite)

### 4. Diff 与 Patch 库
- **需求描述**：对文件或字符串进行内存 Diff 计算与 Patch 应用。
- [mitsuhiko/similar: A high level diffing library for rust based on diffs](https://github.com/mitsuhiko/similar)

### 5. 终端命令执行库
- **需求描述**：运行终端命令并获取返回结果、报错信息。
- 直接执行命令（`program` + `args`）基于 [Tokio](https://github.com/tokio-rs/tokio) 异步运行时，使用 `tokio::process::Command`。
- 文档：[tokio::process::Command](https://docs.rs/tokio/latest/tokio/process/struct.Command.html)

### 6. 拖拽控件与自动粘贴功能
- **需求描述**：支持鼠标拖拽控件到可粘贴文本位置时自动粘贴，以及拖放到浏览器/其他 Shell 输入窗口的跨平台支持。
- 通过前端实现

### 7. 高效文件检索与文本搜索库
- **需求描述**：在文件系统中快速搜索文件和文件内容。
- [grep-regex](https://crates.io/crates/grep-regex) — 用正则搜索文件内容

### 8. 加载 `.gitignore` 作为搜索排除项的库
- **需求描述**：自动加载所有 `.gitignore` 文件规则，作为搜索时的排除选项。
-  [ignore](https://crates.io/crates/ignore) — 遍历目录、自动加载 .gitignore 规则

### 9. 高效的自定义 XML 格式解析库
- **需求描述**：高效、易扩展，支持自定义 XML 格式的解析。
- [tafia/quick-xml: Rust high performance xml reader and writer](https://github.com/tafia/quick-xml)

### 10. 高效易扩展的国际化（i18n）库
- **需求描述**：支持多语言、翻译管理、地区格式化（日期/数字等），且易于扩展。
- 使用[`github:rust-i18n`](https://github.com/longbridge/rust-i18n) / [`crate:rust-i18n`](https://crates.io/crates/rust-i18n)库，使用TOML文件储存翻译文件，`%{}`用于在译文中标记变量，通过`t!`宏来获取并格式化译文。

### 11. 隐私掩码
- **需求描述**：对工具结果中的敏感数据（如邮箱、手机号、身份证、银行卡、API 密钥等）自动进行掩码处理，支持保留前/后若干位，其余字符替换为掩码符号（如 `[PRV_EMAIL_1]`），防止隐私泄露。
- 使用 [`cloakrs`](https://github.com/kadir/cloakrs) 库，内置常见隐私类型的掩码规则，可灵活配置保留位数与掩码样式。

### 12. 多编码兼容的文本处理与转换
- **需求描述**：安全处理命令输出、文件等来源的非 UTF‑8 文本（如 GBK、ASCII 等），自动检测或指定编码转换为 UTF‑8，避免数据丢失。
- 使用 [`encoding_rs`](https://github.com/hsivonen/encoding_rs) 库，支持 40 种编码及 200 余个别名，配合 [`chardetng`](https://github.com/hsivonen/chardetng) 自动检测编码，实现零拷贝、高效解码。
