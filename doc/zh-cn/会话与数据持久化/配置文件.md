# 配置文件

## 项目配置文件
- 路径：`<workspace>/.ManualAid/config.toml`
- 存储项目级设置，包括永久同意规则（`[permissions]` 段）
- 格式：
  ```toml
  [permissions]
  allow_commands = ["gh pr view *", "cargo fmt -- --check"]
  allow_read_paths = ["/data/config/"]
  allow_write_paths = ["/data/output/"]
  allow_edit_paths = ["/data/output/"]
  ```

## 全局配置文件
- 路径：`~/.ManualAid/config.toml`（详见 [ManualAid文件夹](./ManualAid文件夹.md)）
- 存储全局设置（`GlobalConfig`），包括全局永久同意规则
- 规则加载时项目配置优先于全局配置，项目配置可覆盖全局配置
- 规则变更即时生效，无需重启

## 技能启用状态（`[skill]`）

- 仅存在于项目配置文件
- 由 `skill` 相关功能读写，一般无需手改
- 键为技能目录的绝对路径，值为布尔值；手写时路径分隔符需使用 `/` 并为键加引号

```toml
[skill]
"/path/to/skill" = false
```

## 隐私掩码扩展（`[privacy_mask_extension]`）

- 存在于全局与项目配置文件，具体语义与合并规则详见 [隐私掩码与注册表](../权限与审核/隐私掩码与注册表.md)
- `[privacy_mask_extension.regex]`：`类型 = 正则字符串`，按正则匹配
- `[privacy_mask_extension.literal]`：`类型 = 普通文本`，值按字面量在任意位置做子串匹配

```toml
[privacy_mask_extension.regex]
ExamApiKey = "^sk-[A-Za-z0-9]{7}$"

[privacy_mask_extension.literal]
UserName = "Alice"
```

## 默认生成内容

- 由 `manualaid init`（等价于 `dir --init`）生成；文件已存在时不会被覆盖
- 项目与全局配置文件默认内容嵌入`crates\manualaid-core\src\manualaid_dir.rs`文件中
- 配置文件缺失时，`skill` 相关写入会以项目默认模板为基底创建文件，保证新文件始终带注释说明
