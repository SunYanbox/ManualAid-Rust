# 配置文件

## 项目配置文件
- 路径：`<workspace>/.ManualAid/config.toml`
- 存储项目级设置，包括白名单命令（`[permissions]` 段）
- 白名单命令 `allow_commands` 支持"精确匹配 + 通配符匹配"（`*` 匹配零个或多个任意字符）；含链接符（`;`/`&`/`|`）的命令不能命中白名单，需进入审核
- 当前实现只加载 `[permissions].allow_commands`，不存在 `allow_read_paths`、`allow_write_paths`、`allow_edit_paths` 配置项
- 格式：
  ```toml
  [permissions]
  allow_commands = ["gh pr view *", "cargo fmt -- --check"]
  ```

## 全局配置文件
- 路径：`~/.ManualAid/config.toml`（详见 [ManualAid文件夹](./ManualAid文件夹.md)）
- 存储全局设置（`GlobalConfig`），包括全局永久同意规则
- 规则加载时项目配置优先于全局配置，项目配置可覆盖全局配置
- 规则变更即时生效，无需重启

## 技能启用状态（`[skill]`）

- 仅存在于项目配置文件
- 由 `skill` 相关功能读写，一般无需手改
- 键为技能目录的绝对路径，值为布尔值；手写时路径分隔符需使用 `/` 并为键加引号

```toml
[skill]
"/path/to/skill" = false
```

## 界面与调用格式（`[global]`）

- 存在于全局与项目配置，规则加载时项目配置优先于全局配置
- `lang`：界面语言（`en` / `zh-CN`）
- `tool_call_format`：工具调用格式（`auto` / `xml` / `json-codeblock` / `invoke`），默认 `auto`（自动探测）
- `max_result_chars`：复制到剪贴板的结果文本最大字符数，默认 50000
- `context_auto_load`：是否自动加载上下文文件（AGENTS.md 等），默认 true
- 切换交互：配置菜单中显示候选项列表并输入索引直接切换；也支持无参数循环切换；内置命令 `/lang`、`/format` 使用相同交互

```toml
[global]
lang = "zh-CN"
tool_call_format = "auto"
```

## 基础工具开关（`[tools]`）

- 存在于全局与项目配置，规则加载时项目配置优先于全局配置
- `shell` / `read` / `edit` / `write` / `skill`：布尔值，控制该工具是否出现在提示词与工具路由中

```toml
[tools]
shell = true
read = true
edit = true
write = true
skill = true
```

## 隐私掩码扩展（`[privacy_mask_extension]`）

- 存在于全局与项目配置文件，具体语义与合并规则详见 [隐私掩码与注册表](../权限与审核/隐私掩码与注册表.md)
- `[privacy_mask_extension.regex]`：`类型 = 正则字符串`，按正则匹配
- `[privacy_mask_extension.literal]`：`类型 = 普通文本`，值按字面量在任意位置做子串匹配

```toml
[privacy_mask_extension.regex]
ExamApiKey = "^sk-[A-Za-z0-9]{7}$"

[privacy_mask_extension.literal]
UserName = "Alice"
```

## 默认生成内容

- 由 `manualaid init`（等价于 `manualaid dir --init`）生成；文件已存在时不会被覆盖
- 项目与全局配置文件默认内容嵌入 `crates/manualaid-core/src/manualaid_dir.rs` 文件中
- 项目 `.ManualAid` 目录同时生成 `.gitignore`（内容为 `*`），保证项目配置不被提交
- 配置文件缺失时，`skill` 相关写入会以项目默认模板为基底创建文件，保证新文件始终带注释说明
