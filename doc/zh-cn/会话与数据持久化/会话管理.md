# 会话管理
- 启动程序时自动创建会话、数据库和相关配置文件，用户可手动创建新会话。
- 会话记录所有工具调用消息、工具调用结果、审核情况（每项审核的同意/拒绝/拒绝并键入文本，以及永久同意建议的接受/拒绝）与修改结果。
- 会话级数据库存储在项目目录的 `.ManualAid/` 下，使用 Rust SQLite，开启 WAL 模式。项目配置文件也存储在 `.ManualAid/config.toml` 中。
- 允许多个 ManualAid 实例同时运行，每个实例自动创建独立新会话，不会共用会话。数据库写入锁冲突时给予警告并允许重试。
- 会话导出功能：导出为 Markdown 文件，头部包含会话 ID、创建时间；读取工具摘要（文件路径 + 内容，超过 1000 字符部分省略，阈值可配置）；写入工具审核通过的变更（文件路径 + 简短 diff + 增删行数，diff 超过 1000 字符也省略）。其他工具执行记录。需要用户手动补充会话的背景/任务。
- 撤销栈是工具调用结果的一部分，清理时 UI 信息条会提示用户哪些历史编辑无法撤销。
