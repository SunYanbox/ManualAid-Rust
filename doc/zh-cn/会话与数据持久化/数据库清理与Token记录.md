# 数据库清理与Token记录

## 数据库清理
- 用户可在设置/数据管理页面手动清理会话的工具调用结果记录，同时显示数据库总大小、会话数据库大小、统计数据库大小。
- 清理范围仅限工具调用结果记录，**不清理**审核决策记录和永久同意计数（已审核的历史操作记录可清理，但审核本身的状态和智能永久同意的 3 次阈值计数不受影响）。
- 清理会提示用户将失去对应会话的撤销能力。

## Token 消耗记录
- 使用可替换的通用分词器估算累计 Token 消耗并记录到数据库，用于展示为用户节省的 Token 数量。
- **分词器选择**：在 GUI 的设置页面提供下拉菜单，允许用户根据当前使用的 LLM 平台选择对应的分词器类型。
