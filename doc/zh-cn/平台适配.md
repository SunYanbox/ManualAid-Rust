# 平台适配

## Shell 白名单
- 白名单硬编码，使用条件编译区分平台：
  - Windows：`dir` 等
  - Unix/macOS：`ls` 等
  - 通用：`git status`（精确匹配）
- 带参数的白名单命令只维护常用组合，精确匹配。

## 文件锁
- 全局记忆文件使用 Rust 文件锁库，覆盖多平台行为差异。

## 路径处理
- 工作区路径采用 Rust 标准路径处理，以支持跨平台。
- 用户目录位置自动检测（Windows: `C:\Users\<用户名>`, Unix: `/home/<用户名>`, macOS: `/Users/<用户名>`）。

## 图形界面
- 使用跨平台 GUI 库（支持折叠控件、Markdown 显示、鼠标拖拽、弹出窗口）。
- 剪贴板操作跨平台。
