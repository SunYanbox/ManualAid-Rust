# 平台适配

## Shell 白名单
- 白名单硬编码，使用条件编译区分平台：
  - Windows：`dir` 等
  - Unix/macOS：`ls` 等
  - 通用：`git status`（精确匹配）
- 带参数的白名单命令只维护常用组合，精确匹配。

## 文件锁
- 当前版本对配置类文件的幂等创建使用 `file_io::with_file_lock` 加文件锁；记忆文件功能尚未实现。

## 路径处理
- 工作区路径采用 Rust 标准路径处理，以支持跨平台。
- 用户目录位置自动检测（Windows: `C:\Users\<用户名>`, Unix: `/home/<用户名>`, macOS: `/Users/<用户名>`）。

## 图形界面
- 当前版本为 CLI（`manualaid-cli`），尚未提供 GUI；GUI 交互（折叠控件、Markdown 显示、鼠标拖拽、弹出窗口）均为规划。
- 剪贴板操作跨平台，基于 `arboard` 提供真实实现与测试用 Mock。
