# 用户界面与交互流程

> **当前实现状态**：当前版本为 **CLI（命令行界面）** 实现，支持 Windows 11 cmd.exe 和 Ubuntu Desktop 26.04 Bash。以下描述的 GUI 布局（标签页、文件树、按钮等）属于**设计目标**，当前版本通过 TUI（终端用户界面）和交互式命令行循环提供类似功能。

## 布局（设计目标，计划中）
- 顶部：标签页，用于切换主页面/SKILL管理页面/设置页面等
- 左上：文件树。
- 中上：工具记录与结果（默认折叠显示，可滚动）。
- 右上：记录面板。
- 下方左部：输入窗口，右侧按钮分别为“提交”“粘贴并提交”“转换到提示词构建列”。
- 所有面板应支持调整大小，目标最小窗口尺寸为 1000x700 像素。
- **手动模式**/**接受编辑模式**通过快捷键(Shift+Tab)或GUI中的按钮切换，具体行为见[权限策略](./权限与审核/权限策略.md)。
- **控件折叠**：只有具体到显示工具结果、已记录文本的**控件**需要支持折叠，以避免内容过长难以查看。其他面板、输入控件等不需要支持折叠。

## 输入解析规则
1. 如果输入以 `/` 开头且匹配 `/技能名称 ` 或内置命令，则执行对应命令。
2. 否则尝试按当前设置的格式（XML 或 JSON 等）解析工具调用。
3. 均不匹配时在工具记录与结果区域显示红色”无效输入”，不存入数据库。
4. 输入窗口（GUI/TUI）需支持大文本粘贴、文本编辑及控件内换行。

## 配置切换交互（语言与工具调用格式）

- 语言与工具调用格式支持两种切换方式，效果等价：
  1. **列表 + 索引**：显示候选项列表，输入索引直接切换到对应项。
  2. **循环切换**：无参数操作直接切换到列表中的下一项（到尾循环回开头）。
- 配置菜单提供「语言」「工具调用格式」两项；CLI loop 内置命令 `/lang`、`/format` 使用相同交互。
- 切换结果即时生效并写入配置（项目配置优先，未配置时写入项目配置）。

## 工具记录与结果
- 显示工具调用结果，只读工具只保留最新结果。
- 用户可点击查看详情，默认折叠。

## 内联审核卡片

审核卡片在工具记录区域底部内联弹出。多个待审核项依次弹出，未审核项持久化保存。

> 审核触发条件、TUI/GUI 交互细节详见 [审核交互模型](./权限与审核/审核交互模型.md)。

## 智能永久同意建议卡片

当系统检测到用户在同一会话内多次同意相似操作时弹出建议卡片。

> 触发条件、控件交互、规则管理详见 [智能永久同意](./权限与审核/智能永久同意.md)。

## 记录面板（右侧列，低优先级，计划中）
- 用户通过按钮或拖拽将以下内容添加为记录条目：
  - 工具调用结果
  - 已输入内容
  - 当前剪贴板内容
- 条目可标记为三种状态：思考内容、用户补充内容（默认）、工具调用结果，用户可切换。
- 条目持久化到当前会话数据库。
- 点击“整理输出”时，按换行符拼接生成最终文本：
  - 思考内容包裹在 `<think>\n...\n</think>` 中
  - 工具调用结果保持原格式
  - 用户补充内容包裹在 `<user>\n...\n</user>` 中
  - 文件引用展开为 `<file path="相对路径" user="用户提到了可能需要的此文件并提供了其内容">\n文件内容\n</file>`
  - 技能引用展开为 `<skill name="技能名" user="用户提到了可能需要的SKILL并提供了其内容">\n技能描述\n</skill>`
- 整理结果自动复制到剪贴板（默认开启），同时在中间窗口作为“提示词整理工具结果”显示（记录到数据库，但默认不导出到会话 Markdown 文件，除非显式指定）。
- 技能内容通过技能管理器获取，不从文件路径直接读取。

## 文件树
- 暂不支持文件预览。

## 提示词获取
- 系统提示词通过快捷按钮或内置命令 `/ws` 复制到剪贴板。
- 记录面板的整理输出仅用于组合右侧列表内容，不包含系统提示词。

## 撤销提示信息条
- 在会话界面显示文本信息条，提示清理截止时间点，内容随用户删除操作自动更新。
