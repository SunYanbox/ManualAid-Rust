# 智能永久同意

当系统检测到用户在**同一会话**内多次同意相似操作时，主动建议将其添加到永久同意配置。

### 相似度检测规则
- **命令类**（Shell）：对已同意的命令提取命令名（第一个词），若同一命令名被同意达到 **3 次**，触发建议。例如：
  1. 用户同意 `gh pr view 123`
  2. 用户同意 `gh pr view 456`
  3. 用户同意 `gh pr view 789`
  → 弹出建议：是否将 `gh pr view *` 添加到永久同意配置
- **路径类**（Read/Write/Edit）：对已同意的路径提取其父目录，若同一父目录下的操作被同意达到 **3 次**，触发建议。例如：
  1. 用户同意读取 `/data/config/a.toml`
  2. 用户同意读取 `/data/config/b.toml`
  3. 用户同意写入 `/data/config/c.toml`
  → 弹出建议：是否将 `/data/config/*` 添加到永久同意配置

> 计数绑定到单个会话 ID，与会话数据库同生命周期；同一会话重新加载时从数据库恢复，不同会话（不同会话 ID）之间计数隔离。
>
> 高风险命令（`rm`、`git push --force`、`chmod`等）即使达到阈值也不触发建议。

### 建议弹窗交互
触发建议后，在工具记录区域底部弹出建议卡片，包含：
- **描述文本**：说明检测到的模式（如"已 3 次同意 `gh pr view *`"），询问是否将其添加到永久同意配置
- **范围选择**（单选）：
  - **项目**：仅当前项目生效，存储在项目配置文件 `<workspace>/.ManualAid/config.toml` 中
  - **全局**：所有项目生效，存储在全局配置文件 `~/.ManualAid/config.toml` 中（详见 [ManualAid文件夹](../会话与数据持久化/ManualAid文件夹.md)）
- **确认操作**：
  - **同意**：将规则写入对应配置
  - **拒绝**：不添加规则，继续正常流程

### 永久同意规则的数据结构
存储在项目或全局配置文件的 `[permissions]` 段：
```toml
[permissions]
# 命令规则：以命令名精确匹配，通配符 * 表示所有参数
allow_commands = [
    "gh pr view *",
    "cargo fmt -- --check",
]

# 路径规则：支持目录级通配符和文件级精确匹配
allow_read_paths = [
    "/data/config/",
    "/data/shared/",
]
allow_write_paths = [
    "/data/output/",
]
allow_edit_paths = [
    "/data/output/",
]
```

### 规则管理
- 用户可在设置页面/GUI 中手动管理永久同意规则（添加、删除、编辑）。
- 规则加载时项目配置优先于全局配置，项目配置可覆盖全局配置。
- 规则变更即时生效，无需重启。

### 匹配逻辑

规则字符串的匹配遵循通配符语义（`*` 匹配零个或多个任意字符），统称为通配符匹配。

- **命令匹配（通配符）**：将规则字符串作为通配符模式与被审核命令整体匹配（`gh pr view --json` 匹配规则 `gh pr view *`）。
- **命令匹配（精确）**：被审核命令与规则字符串完全相同时即为匹配（`gh pr view` 匹配 `gh pr view`；`gh pr view --json` 不匹配 `gh pr view`）。
- **路径匹配（目录）**：规则路径以 `/` 结尾，被审核路径位于该目录下即为匹配（`/data/config/a.toml` 匹配规则 `/data/config/`）。
- **路径匹配（文件）**：规则路径不以 `/` 结尾且不含 `*`，被审核路径与之完全相同即为匹配（`/data/config/a.toml` 匹配规则 `/data/config/a.toml`；不匹配 `/data/config/b.toml`）。
- **路径匹配（通配符）**：规则路径含 `*`，作为通配符模式与被审核路径匹配（规则 `/data/config/*` 匹配 `/data/config/a.toml` 和 `/data/config/b.toml`，不匹配 `/data/other/file.txt`；规则 `/data/config/*.toml` 匹配 `/data/config/a.toml` 和 `/data/config/b.toml`，不匹配 `/data/config/c.txt`）。
