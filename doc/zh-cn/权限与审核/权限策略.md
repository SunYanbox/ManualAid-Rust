# 权限策略

## 工具权限策略
- 权限基于当前 Agent 配置（例如代码探索 Agent 只有只读工具）。

- Shell 工具可以执行任意命令，非白名单命令默认需要用户审核。

- 白名单命令硬编码，采用条件编译区分平台。白名单命令采用精确匹配，带参数的命令只列出常用固定组合（如 `git status`）。非白名单命令进入审核列表。

- 会话模式：**手动模式**下所有编辑/写入操作均需用户审核；**接受编辑模式**下本会话内工作区中的文件编辑和写入自动放行，工作区外的编辑/写入仍需用户审核。模式切换通过快捷键(Shift+Tab)/GUI中的按钮进行。
  > 模式需要支持未来可能的更多扩展
  
- 完全禁止读写系统文件或用户私密数据。

- 当解析到当前 Agent 无权使用的工具时，在工具输出中给出明确错误并放入结果，不静默跳过。


## 审核决策矩阵

| 工具 | 检查路径 | 检查命令 | 模式依赖 | 工作区外 |
|------|----------|----------|----------|----------|
| Read / Stat | 是 `file_path` / `path` | — | — | 需审核 |
| Glob / Grep | 是 `path`（未传则默认 worktree） | — | — | 需审核 |
| Edit / Write | 是 `file_path` | — | 是 手动→全审；接受编辑→仅区外 | 需审核 |
| Shell | — | 是 `command` | — | — |
| Skill / AskUserQuestion | — | — | — | 始终免审 |

**特殊路径规则**（高于上述矩阵，通过配置 `.ManualAid/config.toml` 中的 `exempt_paths` 实现，非硬编码）：

- 系统文件 / 用户私密数据 → 直接拒绝（`Denied`），不进入审核

## 权限审核（Auditor）

审核器**不硬编码工具名**，而是通过遍历参数的 `semantic` 字段泛化判断。
